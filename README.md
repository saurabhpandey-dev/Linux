⚡ Linux Commands

🚀 A clean, developer-first repository containing essential Linux commands. Each command is formatted into individual plain-text files for rapid lookup, automation parsing, and terminal workflow integration.

🛠️ File Format Specification

Every command in this repository is strictly structured inside its respective file (e.g., pwd.txt, grep.txt) for consistency and automated parsing:

Command: <command_name>
Example: <example_usage>
Description: <detailed_description>


🚀 Key Modules

📁 01. Core File & Directory Ops

Manipulate, navigate, and manage files and directories efficiently.

Navigation & Inspection: pwd • ls • cd • find • ln

File Lifecycle: touch • cp • mv • rm • mkdir • rmdir

Archives & Compression: tar • unzip

📄 02. Text Processing & Stream Editing

Advanced text extraction, filtering, and stream manipulation utilities.

View & Inspect: cat • head • tail • nano

Search & Filter: grep • sort • uniq • wc • diff • patch

Stream Processing: awk • sed • cut • paste • tr

🔐 03. Identity, Access & User Admin

Manage system accounts, user groups, privileges, and session rights.

Permissions: chmod • chown

User Management: useradd • usermod • userdel • passwd • change

Group Admin: groupadd • groupmod • groupdel • gpasswd

Access & Sessions: sudo • su • id • groups • who • write

🌐 04. Networking, Security & Connectivity

Monitor network traffic, diagnose interfaces, inspect sockets, and manage remote connections.

Remote Access & Sync: ssh 

Web & Downloads: curl • wget

Network Diagnostics: ping • traceroute • dig • nmap • nc

Interfaces & Firewalls: ip • netstat • iptables 

⚙️ 05. System Control, Processes & Hardware

Monitor CPU, RAM, active processes, and background services in real time.

Resource Monitoring: free • df • du • top • htop

Process Controls: ps • kill • systemctl

System Info: uname • uptime • whoami • hostname • date • cal

Shell Environment: history • echo • export • env • source • which • whereis

💾 06. Storage, Disks & Filesystems

Low-level disk partition inspection, mounting, and filesystem maintenance.

Block Devices: lsblk • fdisk 

Mounting & Formatting: mount • umount 

⏰ 07. Automation, Scheduling & Logging

Automate background tasks and inspect system event logs.

Task Scheduling: • at

💻 Quick Usage

Clone the repository to quickly inspect or grep commands directly from your terminal:

# Clone the repository
git clone https://github.com/saurabhpandey-dev/Linux

# Move into directory
cd linux-commands-repo

# Search for any command quickly
cat grep.txt
